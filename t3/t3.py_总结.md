# t3.py 文件总结

## 一、文件概述

**文件名**：`t3.py`  
**目的**：MCM 2026 C 问题3的影响分析（Pro dancer + 明星特征）  
**主要功能**：分析职业舞者和名人特征对评委评分和粉丝投票的影响差异

## 二、核心分析流程

### 1. 数据读取与准备（第36-39行）
- 读取官方数据：`2026_MCM_Problem_C_Data.csv`
- 读取粉丝投票估计：`t1/fan_vote_estimates.csv`

### 2. 数据转换：宽表→长表（第42-86行）

**关键步骤**：
- 将每周的多个评委分数（week1_judge1_score, week1_judge2_score...）转换为每周一行
- 计算 `judge_total`：每周所有评委分数之和
- 构造 `pair_id`：`season__celebrity_name`（标识每个参赛单元）
- 计算 `judge_percent`：同一赛季-周内占总分比例
- 标记 `active`：judge_total > 0 表示仍在比赛

### 3. 合并粉丝投票数据（第88-95行）
- 合并粉丝投票估计值（p_mean, CI等）
- 保留不确定性信息（ci_width, rel_ci_width）

### 4. 类别特征简化（第98-111行）

**Top-K 合并策略**：
- **行业（industry_s）**：保留 Top10，其余合并为 "Other"
- **国家（homecountry_s）**：保留 Top10，其余合并为 "Other"
- **舞者（pro_s）**：保留样本量≥25的舞者，其余合并为 "OtherPro"

**目的**：避免虚拟变量过多导致模型不稳定

### 5. 粉丝投票变换与加权（第114-124行）

**Logit 变换**：
```python
fan_logit = log(p_mean / (1 - p_mean))
```

**加权策略**：
- 权重 = 1 / ci_width²（CI越窄，权重越大）
- 99%分位数截断，防止极端值影响

### 6. 主模型构建（第127-146行）

#### 模型A：评委评分模型
```python
judge_z ~ C(season) + C(week) + age_z + C(industry_s) + C(homecountry_s) + C(pro_s)
```
- **方法**：OLS + pair_id 聚类稳健标准误
- **因变量**：标准化后的 judge_total

#### 模型B：粉丝投票模型
```python
fan_z ~ C(season) + C(week) + age_z + C(industry_s) + C(homecountry_s) + C(pro_s)
```
- **方法**：WLS（加权最小二乘）+ pair_id 聚类稳健标准误
- **因变量**：标准化后的 fan_logit
- **权重**：基于 CI 宽度

**标准化目的**：便于跨模型比较同一变量的影响

### 7. 系数对比分析（第149-186行）

**对比项**：
- age_z（年龄）
- C(industry_s)[T.Athlete]（运动员行业）
- C(industry_s)[T.TV Personality]（电视名人）
- C(industry_s)[T.Model]（模特）
- C(homecountry_s)[T.United States]（美国）

**输出指标**：
- `judge_coef_std`：评委模型中的标准化系数
- `judge_p`：评委模型中的 p 值
- `fan_coef_std`：粉丝模型中的标准化系数
- `fan_p`：粉丝模型中的 p 值
- `same_direction`：系数方向是否一致

**输出文件**：`coef_compare.csv`

### 8. Pro Dancer 效应提取（第189-200行）

**提取内容**：
- 每个舞者在两个模型中的固定效应系数（标准化尺度）
- 按系数大小排序

**输出文件**：
- `pro_effects_judges_std.csv`：舞者在评委模型中的效应
- `pro_effects_fans_std.csv`：舞者在粉丝模型中的效应

### 9. 表现模型（weeks_survived）（第203-247行）

**目标**：预测参赛者能走多远（存活周数）

**数据聚合**：
- 按 `pair_id` 聚合，计算：
  - `weeks_survived`：最大周数
  - `mean_judge_percent`：平均评委评分比例
  - `mean_p`：平均粉丝投票份额

**模型序列**（增量R²分析）：

1. **基础模型**：
   ```
   weeks_survived ~ C(season) + mj_z + mp_z
   ```
   - 只包含赛季和平均表现

2. **加入特征模型**：
   ```
   weeks_survived ~ C(season) + mj_z + mp_z + age_z + C(industry_s) + C(homecountry_s)
   ```
   - 加入年龄和行业/国家特征

3. **完整模型**：
   ```
   weeks_survived ~ C(season) + mj_z + mp_z + age_z + C(industry_s) + C(homecountry_s) + C(pro_s)
   ```
   - 加入舞者效应

**输出指标**：
- `R2_base_only_scores`：基础模型 R²
- `R2_add_traits`：加入特征后的 R²
- `R2_add_pro`：加入舞者后的 R²
- `delta_R2_traits`：特征带来的增量 R²
- `delta_R2_pro`：舞者带来的增量 R²
- 各变量的系数

**输出文件**：`performance_weeks_model.csv`

### 10. Pro Dancer 一致性分析（第250-283行）

**分析内容**：
- 计算舞者在评委模型和粉丝模型中的系数相关性
- 相关性高 → 舞者对两侧影响一致
- 相关性低 → 舞者对两侧影响不同

**输出文件**：`quick_summary.txt`

**包含内容**：
- 两个模型的 R²
- 加入 pro 的增量 R²
- Pro 效应的相关系数

## 三、输出文件清单

1. **`coef_compare.csv`**：关键变量的系数对比（评委 vs 粉丝）
2. **`pro_effects_judges_std.csv`**：舞者在评委模型中的效应
3. **`pro_effects_fans_std.csv`**：舞者在粉丝模型中的效应
4. **`performance_weeks_model.csv`**：表现模型的增量 R² 分析
5. **`quick_summary.txt`**：快速总结（R²、增量 R²、相关性）

## 四、方法学特点

### 1. 稳健性
- **聚类稳健标准误**：使用 `pair_id` 聚类，处理同一参赛者的重复观测
- **加权最小二乘**：粉丝模型使用 CI 宽度加权，考虑估计不确定性

### 2. 可解释性
- **标准化变量**：便于跨模型比较
- **增量 R²**：量化不同因素对解释力的贡献
- **固定效应**：season, week, pro_s 作为固定效应，控制不可观测异质性

### 3. 对比分析
- **同一套自变量**：两个模型使用相同的解释变量
- **标准化系数**：便于直接比较影响大小
- **方向一致性**：检查系数方向是否一致

## 五、核心研究问题

1. **职业舞者是否影响表现？**
   - 通过提取 pro_s 的固定效应系数
   - 通过增量 R² 量化贡献

2. **舞者对评委和粉丝的影响是否一致？**
   - 通过系数相关性分析
   - 通过方向一致性检查

3. **名人特征（年龄、行业、国家）的影响如何？**
   - 通过系数对比分析
   - 通过增量 R² 分析

4. **哪些因素能预测"走多远"？**
   - 通过表现模型（weeks_survived）
   - 通过增量 R² 分解各因素贡献

## 六、与 Q3.ipynb 的关系

- **t3.py**：更简洁的脚本版本，专注于核心分析流程
- **Q3.ipynb**：更详细的分析，包含更多诊断、可视化和深入分析

两者方法学一致，但 Q3.ipynb 提供了更丰富的分析和解释。
